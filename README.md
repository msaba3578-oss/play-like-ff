# Play Like Pro

Flutter esports frontend with Android build configuration and GitHub Actions APK build.

## GitHub phone build
1. Create a GitHub repository.
2. Upload all files/folders from this project to the repository root.
3. Open Actions.
4. Select `Build Play Like Pro APK`.
5. Tap `Run workflow`.
6. Open the completed run and download the `play-like-pro-apk` artifact.

## Local build
flutter pub get
flutter run
flutter build apk --release
